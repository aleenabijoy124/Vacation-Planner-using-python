# Vacation-Planner-using-python
A Python-based Vacation Planner using Pandas and Matplotlib to explore tourist destinations, analyze travel costs, ratings, visa requirements, and visitor trends through data manipulation, CSV operations, and interactive visualizations.

# 🌍 TripInsight – Python Vacation Planner

## Project Overview
TravelWise is a menu-driven Vacation Planner developed using Python, Pandas, and Matplotlib. The project focuses on analyzing tourism data to help users explore destinations based on travel costs, popularity, accommodation availability, visa requirements, and tourist ratings.

## Objectives
- Analyze tourism data using Python and Pandas.
- Identify affordable and highly rated travel destinations.
- Compare tourist arrivals, hotel availability, and travel expenses.
- Perform data manipulation and CSV operations.
- Visualize tourism trends using graphs.

## Technologies Used
- **Python** – Programming language
- **Pandas** – Data analysis and manipulation
- **Matplotlib** – Data visualization
- **CSV** – Data storage and retrieval

## Key Features

### 1. Tourist Destination Database
Explore 44 destinations worldwide, including details about attractions, costs, accommodation, and visitor ratings.

### 2. Data Analysis
Perform 12 different analytical queries, including:
- Finding budget-friendly destinations.
- Identifying highly rated cities.
- Exploring destinations with fewer tourists.
- Comparing tourism popularity.
- Filtering destinations based on visa requirements.
- Analyzing hotel availability and tourist arrivals.

### 3. Data Manipulation
Add new destinations, rename columns, and delete existing records or features.

### 4. CSV Operations
Save tourism data into CSV files and load existing datasets.

### 5. Data Visualization
Generate graphs to:
- Compare travel costs.
- Examine the most visited cities.
- Analyze average stay durations.
- Explore relationships between hotel availability and tourist arrivals.

## How to Run
1. Install Python.
2. Install the required libraries:

   `pip install pandas matplotlib`

3. Run the Python program.
4. Select an option from the interactive menu.

## Conclusion
TravelWise demonstrates how Python can transform tourism data into meaningful insights through filtering, sorting, data manipulation, and visualization. The project highlights the practical applications of data analysis in travel planning and decision-making.
